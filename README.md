# Alberto Reyes Castro — AI Engineering Portfolio

Recruiter-facing portfolio for **Alberto Reyes Castro**, Applied AI Engineer in London.

**Live site:** https://albertoreyescastro.github.io/

The portfolio is positioned around:

- multimodal and on-device machine learning;
- reliable AI and multi-agent orchestration;
- model evaluation and technical tooling;
- hardware-aware speech inference;
- scientific computing and technical communication.

## Source-of-truth policy

Project repositories are the canonical source for project-specific code, reports, demos, validation evidence and limitations. The portfolio links to those sources rather than maintaining stale duplicate copies where possible.

Key public projects include:

- [Agent Control Center](https://github.com/albertoreyescastro/agent-control-center)

## Implementation

The site is intentionally lightweight: semantic HTML, a small standalone stylesheet and minimal JavaScript for the footer year. It includes responsive layouts, keyboard focus styles, a skip link, reduced-motion handling, canonical/Open Graph metadata and structured person metadata.

The public CV is maintained separately from the website refresh so that CV revisions can be reviewed independently.
