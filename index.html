03 ML evaluation tooling

MODELHAWK

Static Technical Auditing for ML Notebooks

Next.js/TypeScript tooling that parses Jupyter notebooks without executing them and surfaces deterministic evidence about risky ML workflow patterns.

Checks cover test-set reuse, threshold tuning against held-out labels, preprocessing before cross-validation, leakage/resampling patterns, weak metrics, reproducibility gaps and unsupported model-selection claims. The deterministic audit remains the source of evidence; an optional examiner adds narrative guidance rather than replacing it.
