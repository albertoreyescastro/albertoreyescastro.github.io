Applied ML · Product collaboration

TeachScribe — On-Device Multimodal Retrieval

TinyCLIP 39M/16 · INT8 ONNX Runtime · 441 ms median / 459 ms P95 · Android 7 tablet

Designed, built and evaluated a standalone Android prototype that ranks local photos against written observations using fully on-device image–text inference, with a person confirming every match. I benchmarked five pretrained vision–language models on curated retrieval evaluations using Hit@1 and Hit@5 alongside model size, CPU cost, mobile deployability and checkpoint licensing. TinyCLIP 39M/16 reached 17/20 Hit@1 and 18/20 Hit@5 on a 20-query desktop evaluation with 16 candidate images.

Optimised the mobile path with INT8 quantisation, reusable inference sessions, native Kotlin preprocessing and a persistent SQLite embedding cache. Dynamic INT8 quantisation reduced the text encoder from approximately 170 MiB to 43 MiB (−74.8%). Keeping image sessions lazy held idle memory at 76.3 MiB PSS versus 166.6 MiB with preloading. On a Huawei MediaPad M3 Lite 8 running Android 7, 108/108 cached searches over 44 photos completed at 441 ms median and 459 ms P95; physical-device testing also covered functional acceptance, sustained load, thermal behaviour and battery-side energy.

Source code, product data and internal product materials remain private.

ModelHawk — ML Notebook Audit Prototype

Static analysis · deterministic audit · Gemini API · local Llama/Ollama fallback · LaTeX/PDF

Next.js/TypeScript tool that audits classification notebooks, especially on imbalanced data. It parses code and Markdown cells and applies deterministic and heuristic checks for leakage risk, metric choice, class imbalance, validation quality and reproducibility.

Optional examiner notes come from the Gemini API, with a local Llama 3.2 fallback through Ollama; the core audit remains usable without an external LLM. Results are exported as LaTeX/PDF audit reports.
