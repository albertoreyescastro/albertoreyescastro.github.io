ModelHawk — ML Notebook Audit Prototype

Static analysis · deterministic findings · optional AI-assisted review · LaTeX reporting

Developer tool for reviewing structured machine-learning notebooks. It parses code and Markdown, identifies workflow signals and applies deterministic and heuristic checks around leakage risk, class imbalance, metric choice, validation quality, reproducibility and portfolio readiness.

An optional AI review layer can add examiner-style questions and commentary while deterministic operation remains available without an external model. Findings are compiled into professional LaTeX reports.
