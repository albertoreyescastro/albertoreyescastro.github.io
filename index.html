Applied AI · Production pipeline

TeachScribe — On-Device Multimodal Photo Retrieval

TinyCLIP 39M/16 · INT8 ONNX Runtime · Android · measured physical-device evidence

Designed, built and evaluated an Android pipeline that ranks local classroom photos against written observations using fully on-device image–text inference, while keeping the teacher as the final decision-maker. I compared five pretrained vision-language models, selected TinyCLIP 39M/16 and deployed separate INT8 text/image encoders with native Kotlin preprocessing and persistent RAM + SQLite embedding reuse.

On a Huawei MediaPad M3 Lite 8 running Android 7, 108 consecutive cached searches over 44 photos completed at 441.07 ms median / 459.28 ms P95. INT8 reduced the text encoder from 178,520,196 to 45,042,123 bytes (−74.77%), and lazy image-model loading kept idle memory at 76.3 MiB PSS versus 166.6 MiB for the rejected preload variant. The pipeline has been integrated into TeachScribe and shipped within its deployment to 50+ UK schools; that figure is deployment reach, not measured adoption of this specific feature.

The public engineering case study preserves architecture, de-identified evidence, validation outcomes and trade-offs while withholding TeachScribe-owned application source, product data and reusable implementation details.

ML evaluation tooling

ModelHawk — Static Technical Auditing for ML Notebooks

Deterministic audit · regression-tested rules · optional AI examiner · Docker production E2E

Next.js/TypeScript tool that parses Jupyter notebooks without executing them and applies deterministic checks for issues such as test-set reuse, threshold tuning against held-out labels, preprocessing before cross-validation, weak metrics and reproducibility gaps.

The deterministic audit remains the source of evidence. An optional examiner layer can add narrative guidance through an external provider or local fallback, while the deployed service can operate without a hosted AI key. CI builds the production Docker image and exercises health, audit and PDF-report routes through the same HTTP boundary used by the deployment.
